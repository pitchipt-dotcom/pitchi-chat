# コードの由来とライセンス範囲

## 自作部分

Pitchi-chatとPitchi-workは、管理者が設計し、Codex等のAIを利用して開発したプロジェクトです。
BONSAIは以前利用していた外部LLMの名前です。旧BONSAI連携ハーネスのHost・CLI・検証ロジックは、同じ管理者の開発プロジェクトに属します。

公開前に、旧ハーネスのGit履歴、抽出元マニフェスト、保存されたソースのSHA256、現行関数との対応を確認しました。
Pitchi-workの移行履歴で集合名義となっていた49コミットは、旧ハーネスの同一管理者名義の49コミットと件名・時刻が対応し、3,829件の同一パスのファイル版が一致しました。移行用名義だけを外部貢献者とは扱っていません。
抽出マニフェストの13ソースは、固定された旧ハーネスのコミットと全件SHA256が一致しました。

## 外部のBONSAI公式実装との区別

比較対象は[PrismML-Eng/Bonsai-demo](https://github.com/PrismML-Eng/Bonsai-demo)のコミット`17b143e889a45c090816b520e79a50c996164e1f`です。
[公式LICENSE](https://github.com/PrismML-Eng/Bonsai-demo/blob/17b143e889a45c090816b520e79a50c996164e1f/LICENSE)はApache-2.0です。
公開コピーのChat 171、Work 133ソースを対象に、Python関数のASTと8行の実コードの連続一致を検査し、公式実装との一致は検出されませんでした。
これは指定版と指定方法での検査結果であり、あらゆる第三者コードとの同一性を保証するものではありません。
公式エンジンのソース・実行ファイル・モデルweightsは同梱していません。
